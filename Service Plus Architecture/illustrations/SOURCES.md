# Illustration sources

Artwork by Katerina Limpitsouni at unDraw, obtained 18 October 2026.

- `undraw_login.svg`: Log in, https://undraw.co/illustration/login_weas
- The following artwork was obtained from the rendered SVG previews on https://undraw.co/search/account : Access account, User Account, Onboarding, Forgot Password, Message Sent, Authentication, Team, Team Permissions.
- SVG previews use `currentColor` for their customizable accent. The saved assets resolve that accent to `#0F766E`.
- PNG files are faithful raster versions of the saved SVGs for portable PowerPoint embedding.
- Authentication artwork includes a fingerprint motif and is intentionally not used in this functional deck, which does not choose a biometric sign-in method.
- Repeated actor illustrations deliberately keep the same visual meaning across citizen and official flows.
